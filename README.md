# ExpenseTrackerPro

A premium modern expense tracker iOS application built using SwiftUI.

## 🚀 Tech Stack

- SwiftUI
- MVVM Architecture
- Swift
- Dark Mode UI
- Modular Scalable Structure

## 📱 Features

- Animated Splash Screen
- Onboarding Flow
- Expense Tracking
- Analytics Dashboard
- Premium Fintech UI

## 🏗 Architecture

The project follows:
- MVVM Architecture
- Feature-based folder structure
- Reusable UI components
- Scalable app structure
